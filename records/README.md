# Record tables

Line-oriented files the app shows as tables edited in place (`RecordTableView`):

- `Procfile` — process types and their commands.
- `ssh_config` — Host and Match blocks with their options; the leading options apply to every host.

The hosts file, crontab and gettext catalog fixtures are the showcases in `../languages/hosts/`,
`../languages/crontab/` and `../languages/gettext/`; the notebook is `../structured/analysis.ipynb`.
All names are fictional and every address is under example.com or a documentation range.
