# Sidewatch Guide

A demo document for today's preview work: find, zoom, scroll, math, tables, and the heading path.

## Install

Clone the repo and run the build. It costs $5 and $10 is the upper bound, neither is math.

- `swift build`
- `./bundle.sh`
- `./check.sh`

## Usage

Click into this rendered pane and press ⌘F to search it. Press ⌘= to zoom, ⌘0 to reset, or pinch.

### Flags

| Flag | Meaning | Default |
|---|---|---|
| `--selftest-preview-page` | find, zoom, scroll, math | off |
| `--selftest-config-views` | YAML tree, .env table | off |
| `--selftest-markdown` | the formatting bar, tables, the heading path | off |

Put the caret in the table above and use the bar's Table button: Format Table, add a column, delete a row.

### Math

Inline: the energy $E = mc^2$ and the sum $\sum_{i=1}^{N} x_i$.

Display:

$$
\mathcal{L}(\theta) = \underbrace{\frac{1}{N}\sum_{i=1}^{N} \| f_\theta(x_i) - y_i \|_2^2}_{\text{accuracy}} + \lambda \underbrace{\|\theta\|_1}_{\text{simplicity}}
$$

```sh
echo $PATH $x$ done
```
